# Toilet nær mig

Funktionen finder offentlige toiletter via OpenStreetMap Overpass inden for cirka 5 km.

## Funktioner

- Bruger rejsemålet som sikker standardposition.
- Kan efter tydeligt samtykke bruge enhedens aktuelle GPS-position.
- Sorterer efter afstand og viser anslået gåtid.
- Filtre for gratis adgang, handicapadgang og puslebord.
- Viser åbningstider, pris og tilgængelighed, når data findes.
- Links til Google Maps, rutevejledning og OpenStreetMap.
- Lokal cache i 30 minutter.
- Ingen opdigtede oplysninger.
